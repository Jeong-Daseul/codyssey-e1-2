# E1-2 Python·Docker·Git 퀴즈 게임

## 프로젝트 개요

Python, Docker, Git 기초 개념을 학습할 수 있는 콘솔 퀴즈 게임이다.
퀴즈를 풀고, 새 퀴즈를 등록하고, 점수와 게임 기록을 저장할 수 있다.

## 실행 방법

PowerShell에서 프로젝트 폴더로 이동한 뒤 실행한다.

```powershell
cd D:\2026_Codyssey\e1-2_quiz
python main.py
```

## 메뉴

1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 퀴즈 삭제
6. 종료

## 구현 기능

- `Quiz` 클래스: 문제, 선택지 4개, 정답 관리
- `QuizGame` 클래스: 게임 진행 및 전체 데이터 관리
- 기본 퀴즈 5개 제공
- 퀴즈 추가·목록·삭제
- 정답·오답 판정 및 점수 계산
- 최고 점수 저장
- 게임 날짜·문제 수·정답 수·점수 기록 저장
- 잘못된 메뉴·정답 번호 입력 처리
- `state.json`이 없거나 손상된 경우 기본 퀴즈로 복구

## 파일 구조

```text
e1-2_quiz/
├─ main.py       # Quiz, QuizGame 클래스와 실행 코드
├─ state.json    # 퀴즈·최고 점수·게임 기록 저장
└─ README.md     # 실행 방법과 기능 설명
```

## 데이터 저장 형식

`state.json`은 UTF-8 JSON 형식으로 저장한다.

```json
{
    "quizzes": [
        {
            "question": "문제",
            "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
            "answer": 1
        }
    ],
    "best_score": 100,
    "history": [
        {
            "played_at": "2026-07-28T20:00:00",
            "total_questions": 5,
            "correct_answers": 5,
            "score": 100
        }
    ]
}
```

## 실행 검증 결과

- 기본 퀴즈 5개 목록 출력 성공
- 퀴즈 5문제 모두 정답 처리 성공
- 최고 점수 100점 저장 성공
- 게임 기록 1회 저장 및 출력 성공
- 퀴즈 추가 후 6개 목록 확인 성공
- 퀴즈 삭제 후 5개로 복구 성공
- 프로그램 재실행 후 저장된 퀴즈와 점수 유지 확인
